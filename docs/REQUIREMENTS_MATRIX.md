# Requirements and verification matrix

**Met** means the feature is implemented at the development stage and has the evidence indicated. **Partial** means some acceptance criteria still need work. **Pending** means the module is missing. **Deferred** means production work is scheduled after acceptance. The coverage below uses synthetic data. Real staff accounts, office GPS accuracy, Windows server operations and the production site require later acceptance.
